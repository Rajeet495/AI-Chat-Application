\# AI Chat Application



A simple conversational AI application built using Python and Streamlit.



\## Features



\- User input through a chat interface

\- AI-generated responses

\- Conversation history

\- Custom AI instructions

\- Error handling

\- Streamlit web interface

\- Local LLM support using Ollama and Qwen3:4b



\## Technologies Used



\- Python

\- Streamlit

\- Ollama

\- Qwen3:4b

\- Requests



\## Project Architecture



User

↓

Streamlit Interface

↓

Python Application

↓

Conversation History

↓

LLM API

↓

AI Response

↓

Streamlit Interface
